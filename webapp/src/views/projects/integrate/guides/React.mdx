## Install the packages

You will need `@lokale/react` to use `<T>` component or `useTranslate` hook.

```sh
npm install @lokale/react
```

## Setup your environment

Add this to your `.env.development.local`.

```dotenv
VITE_APP_TOLGEE_API_URL={{{apiUrl}}}
VITE_APP_TOLGEE_API_KEY={{{apiKey}}}
```

## Use LokaleProvider

Wrap your main `App` component with Lokale provider.

```typescript jsx
import { Lokale, DevTools, LokaleProvider, FormatSimple } from "@lokale/react";

const lokale = Lokale()
  .use(DevTools())
  .use(FormatSimple())
  .init({
    language: 'en',

    // for development
    apiUrl: import.meta.env.VITE_APP_TOLGEE_API_URL,
    apiKey: import.meta.env.VITE_APP_TOLGEE_API_KEY,

    // for production
    staticData: {
      ...
    }
  });

...

<LokaleProvider
  lokale={lokale}
  fallback="Loading..." // loading fallback
>
  <App />
</LokaleProvider>
```

## Use Lokale!

```typescript jsx
import { T } from "@lokale/react";

...

<T keyName="translation_key" />
```

or

```typescript jsx
import { useTranslate } from "@lokale/react";

...

const { t } = useTranslate();

...

t("key_to_translate")
```
