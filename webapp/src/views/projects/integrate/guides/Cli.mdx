## Load translations with Lokale CLI

To install Lokale CLI globally run:

```sh
npm install --global @Lokale/cli
```

Login with project API key:

```sh
Lokale login "{{{apiKey}}}"
```

Pull translations into desired folder:

```sh
Lokale pull --project-id={{{projectId}}} --path ./i18n
```
