## Add Lokale libraries to your Web page

You need `@lokale/web` library to translate your texts:

```html
<script src="https://cdn.jsdelivr.net/npm/@lokale/web/dist/lokale-web.umd.min.js"></script>
```

## Setup Lokale

```javascript
// index.js
const { Lokale, InContextTools, FormatSimple, BackendFetch } =
  window['@lokale/web'];

const lokale = Lokale()
  .use(InContextTools())
  .use(FormatSimple())
  .use(BackendFetch())
  .init({
    // ############################################################
    // ## you should never leak your API key                     ##
    // ## remove it in for production publicly accessible site   ##
    // ############################################################
    apiKey: '{{{apiKey}}}',
    apiUrl: '{{{apiUrl}}}',
    defaultLanguage: 'en',
    observerType: 'text',
    observerOptions: { inputPrefix: '{{', inputSuffix: '}}' },
  });

lokale.run();
```

## Do stuff when Lokale is loaded (optional)

```javascript
lokale.run().then(() => {
  document.getElementById('loading').style.display = 'none';
});
```

## Use Lokale

```html
<h1>{{hello_world}}</h1>
```

or

```javascript
lokale.on('update', () => {
  document.title = lokale.t('lokale_example_title', { noWrap: true });
});
```
