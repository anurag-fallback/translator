## Install the packages

You will need `@lokale/vue` to use `<T>` component or `LokaleMixin` with `$t` function.

```sh
npm install @lokale/vue
```

## Setup your environment

Add this to your `.env.development.local`.

```dotenv
VITE_APP_TOLGEE_API_URL={{{apiUrl}}}
VITE_APP_TOLGEE_API_KEY={{{apiKey}}}
```

## Use LokaleProvider

Wrap your whole app with Lokale provider.

```ts
import { Lokale, DevTools, VueLokale, FormatSimple } from '@lokale/vue';

const lokale = Lokale()
  .use(DevTools())
  .use(FormatSimple())
  .init({
    language: 'en',

    // for development
    apiUrl: process.env.VITE_APP_TOLGEE_API_URL,
    apiKey: process.env.VITE_APP_TOLGEE_API_KEY,

    // for production
    staticData: {
      ...
    }
  });

...

app.use(VueLokale, { lokale });

...

<template>
  <LokaleProvider>
    <template v-slot:fallback>
      <div>Loading...</div>
    </template>
    <App />
  </LokaleProvider>
</template>
```

## Use Lokale!

```html
<template>
  <div :title="$t('translation_key')">Hello</div>
</template>
```

or

```html
<template>
  <T keyName="translation_key" />
</template>

<script>
  import {T} from "@lokale/vue";

  ...
</script>
```
