To use Lokale with NPM, please visit [docs](https://lokale.io/js-sdk/initialization).

It works fine with Webpack or Rollup projects! ;)

## Install packages

```sh
npm install @lokale/web
```

## Create Lokale instance

```javascript
import { Lokale, FormatSimple, DevTools, BackendFetch } from '@lokale/web';

const lokale = Lokale()
  .use(DevTools())
  .use(FormatSimple())
  .use(BackendFetch())
  .init({
    // ############################################################
    // ## you should never leak your API key                     ##
    // ## remove it in for production publicly accessible site   ##
    // ############################################################
    apiKey: '{{{apiKey}}}',
    apiUrl: '{{{apiUrl}}}',
    defaultLanguage: 'en',
    observerType: 'text',
    observerOptions: { inputPrefix: '{{', inputSuffix: '}}' },
  });

lokale.run();
```

## Do stuff when Lokale is loaded (optional)

```javascript
lokale.run().then(() => {
  document.getElementById('loading').style.display = 'none';
});
```

## Use Lokale!

```javascript
lokale.on('update', () => {
  document.title = lokale.t('lokale_example_title', { noWrap: true });
});
```
